# ServiceHub

Website đặt lịch và quản lý dịch vụ trực tuyến.

## Công nghệ sử dụng

- ASP.NET Core 10 MVC
- Razor Views, Bootstrap, JavaScript
- SQL Server, Entity Framework Core
- ASP.NET Core Identity
- RESTful API
